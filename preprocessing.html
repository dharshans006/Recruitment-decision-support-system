Decision Tree ML Preprocessing Pipeline

1

Missing Value Imputation

The system scans all data fields. Numeric metrics (Technical Score, Experience, etc.) are filled with their respective column median to prevent outlier distortion. Categorical fields are filled with the column's most frequent value (Mode).

Completed
2

Duplicate Removal

Scans matching record sets based on Candidate_ID and attributes. Duplicates are deleted to prevent model bias and ensure unique samples for the Decision Tree training process.

Completed
3

Label/Categorical Encoding

Categorical attributes (Education Level, Certifications, etc.) are converted into numerical codes using Scikit-learn's LabelEncoder. This prepares strings for mathematical processing in the decision split nodes.

Completed
4

Feature Selection

Subsets columns into input features: ['Education', 'Experience', 'Technical_Score', 'Communication_Score', 'Aptitude_Score', 'Certifications', 'Python', 'Java', 'SQL', 'PowerBI', 'Excel'] and sets the target classifier variable to Selected_Role.

Completed
5

Train-Test Data Split

Splits the clean database into an 80% Training set (to fit the decision paths) and a 20% Testing set (to evaluate accuracy parameters and confusion matrices dynamically).

Completed
